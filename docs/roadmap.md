## 実接続で確認したいこと

- [ ] `/start` の確認ボタンから収集が始まり、**開始の知らせが1通だけ**であること
- [ ] 動画が**ボスごとの正しいチャンネル**に投稿されること。判定不能なものが fallback へ行くこと
- [ ] タイトルと URL の2行投稿で、Discord が動画カードを展開すること
- [ ] `/stop` が収集件数サマリを出すこと（3秒の応答期限内に defer できているか）
- [ ] OR クエリの検索結果（5ボス分が 50 件の枠に収まるか、無関係な動画がどれだけ枠を食うか）
- [ ] 投稿ログ（`logs/bot.jsonl`）を見て、エイリアスの過不足を運用者と調整する
- [ ] NG ワードが効きすぎ / 効かなすぎでないか
