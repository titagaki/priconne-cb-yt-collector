# 攻略動画の表記慣習

YouTube のクラバト攻略動画で、投稿者が慣習的に使う表記。**ここに書くのはゲーム側の事実**で、
Bot が何を拾うかとは独立している。

現在 Bot が判定に使うのは**ボス名とエイリアスだけ**（[04](../spec/04-collection.md) §2）。
持ち越し・フルオート・トレモ・段階の表記は、実在するが判定には使わない。
以前は使っていたので、再び拾う判断をするときの資料としてここに残す。

実例は [`docs/reference/priconne_cb_2026-07_full.html`](../reference/priconne_cb_2026-07_full.html)
（2026年7月にボス名で検索した全126件。無関係な動画も含む）。

## タイトルに「プリコネ」が入るとは限らない

「ワイバーン 水魔法v2 46585 m1」「オルレオン 3.55くらい」「ライデン妥協3.5 マス93」のように、
**ゲーム名もクラバトの語も入らないタイトルが珍しくない。** 「プリンセスコネクトRe:dive」と
正式名称で書く例もある。

したがってプリコネ文脈語の有無を必須条件にすると取りこぼす。検索クエリにも入れない
（[discussion/動画の取得](../discussion/collection.md#検索はボス名だけで行う)）。

## ボスの指し方

### ボス名

「ワイバーン」「スピリットホーン」など、そのままの名前。略称も広く使われる（「スピホン」「デミカリ」など）。
**略称は月ごと・コミュニティごとに揺れる**ため、網羅的な一覧は存在しない。

### EX表記

ボスを名前ではなく**番号**で表す記法。

| 表記 | 例 |
|---|---|
| `exN` | ex1、EX 1、ex-1 |
| `Nボス` | 1ボス、4ボス |
| `ボスN` | ボス3 |
| `第N[ボス\|弾]` | 第2ボス |
| 丸数字 | ①〜⑤ |

**この表記はその月のボス構成を知らないと意味を持たない。** 「4ボス」が何を指すかは月によって変わる。
また `ex1` のような文字列は他ゲーム・他コンテンツでも使われるため、単体では識別力がない。

## 凸種別

### 持ち越し

「持ち越し」「持越し」「持越」「もちこし」。
**「繰り越し」「繰越」は使われない。**

秒数を併記することが多い。**単位は `s` が圧倒的に多く、`秒` はまれ**
（[2026年7月の実データ](../reference/priconne_cb_2026-07_full.html)では `s` 21件に対し `秒` 1件）。

```
24s持ち越し編成 / 持ち越し38s / 21s 持ち越し
35秒持ち越し / 持ち越し20秒 / 45秒から
```

**持ち越し語を伴わず秒数だけ書く形も多い**（「4段階 オルレオン 11145万 34s」）。
フルタイムが90秒なので、それより短い秒数が単独で書かれていれば持ち越しを意味する。
逆に `90秒` / `90s` 単独はフルタイム＝通常を指す。

「持ち」単体は**持ち越しを意味しない**。「持ち込み」「気持ち」など無関係な語に頻出する。

### 通常

「通常」「通常編成」「通常凸」「初手」「初凸」「素凸」「1凸目」「フルタイム」「90秒」「90s」。

## 操作方法

- **フルオート**: 「フルオート」「フルオ」「full auto」。オート操作で完走する編成
- **手動**: 「手動」「マニュアル」

「フル」だけでは通常編成（フルタイム）とフルオートの区別がつかない。**「フルオ」はフルオートの略**であり、
通常編成を指すものではない。

## ダメージ量

「2150万」「1.5億」「2億3000万」「2,150万」。億と万が併記される場合は合算した値を指す。

## その他の頻出語

判定には使っていないが、実データで頻出するもの。

- **段階**: 「4段階目」「4段階」。ボスの強化段階（[クランバトル](clan-battle.md#段階)）
- **目押し**: 手動でタイミングを合わせる操作。「目押し8」「目押しなし」のように箇所数を書く
- **属性**: 「【水魔】」「【闇物】」「【風物】」など、編成の属性と物理/魔法を角括弧で示す
- **消滅**: 特定の編成タイプを指す語。「魔法消滅編成」「消滅凸」

## トレーニングモード撮影

「トレーニングモード」「トレモ」「練習モード」「検証」。

トレモで撮影された動画は本番と条件が異なる場合があるため、視聴者にとって区別できることに意味がある。
