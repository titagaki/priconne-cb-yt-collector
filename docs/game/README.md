# ゲーム知識

プリンセスコネクト!Re:Dive 側の事実をまとめる。**この Bot の仕様ではなく、Bot が前提としているゲームの仕様。**

ここに書くもの:

- ゲームのルール・スケジュール・用語（クラバトの開催日程、ボスの段階、持ち越しの仕組みなど）
- 攻略動画の投稿者が使う慣習的な表記

ここに書かないもの:

- Bot が何をするか → [`docs/spec/`](../spec/README.md)
- なぜその仕様にしたか → [`docs/discussion/`](../discussion/README.md)
- 実際に取得した動画リスト → [`docs/reference/`](../reference/README.md)
