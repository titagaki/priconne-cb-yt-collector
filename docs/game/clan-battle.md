# クランバトル（クラバト）

プリンセスコネクト!Re:Dive の月次レイドイベント。クラン単位でボスに挑み、与ダメージを競う。

## 開催スケジュール

月末の数日間に開催される。

| 期間 | 日程の目安 | 内容 |
|---|---|---|
| トレーニングモード | 本番開始の**3日前**から | 今月のボス構成が公開され、練習できる |
| 本番 | **末日の5日前 〜 1日前**（5日間） | 実際にダメージを競う |

例（末日が31日の月）:

```
23日 ────────── 26日 ──────────────── 30日   31日
 └ トレモ開始    └ 本番開始           └ 本番終了  └ 末日
 ├──── トレモ ────┤├────── 本番 ───────┤
```

| 末日 | トレモ開始 | 本番 |
|---|---|---|
| 31日 | 23日 | 26日〜30日 |
| 30日 | 22日 | 25日〜29日 |
| 29日 | 21日 | 24日〜28日 |
| 28日 | 20日 | 23日〜27日 |

**実際の開催日程は月ごとに前後する。** 上記は末日基準の目安であり、運営のアナウンスが優先される。
ゲーム内のメンテナンス日程やイベントの都合でずれる月がある。

## ボス

- 1周につき **5体**を順に討伐する。順番は固定（1ボス → 5ボス）
- ボス構成は**毎月入れ替わる**。トレーニングモード開始時点で判明する
- 5体すべてを討伐すると次の周回に進む

### 段階

周回が進むごとにボスが強化される。これを「段階」と呼び、**1〜5段階目**まである。

同じボスでも段階によって HP と行動パターンが変わるため、通用する編成が異なる。

**トレーニングモードでは全段階を自由に選んで挑戦できる。** 段階はクランの周回進行に紐づく値であり、
どの段階を練習するかは任意に選べる。

## 凸（挑戦）

1人1日3回まで挑戦できる。この1回を「凸」と呼ぶ。

### 通常

満タンの残タイム **90秒**で挑む編成。

### 持ち越し

前の凸でボスを討伐した際、残り時間が次の挑戦に引き継がれる。この引き継いだ時間で挑む編成を
「持ち越し」と呼ぶ。持ち越せる時間は**最大90秒**で、実際には討伐時の残り時間による（20秒、35秒など）。

持ち越しは時間が短いぶん、通常とはまったく別の編成が要求される。攻略動画でも通常と持ち越しは
明確に分けて扱われる。

## トレーニングモード

本番前の練習機能。

- **回数無制限**で挑戦できる
- **全段階**を自由に選べる
- 本番と条件が異なる場合がある（持ち越し検証が本番どおりに再現できないなど）

トレモ期間中に今月のボス構成が判明するため、**この時点から検証動画が投稿され始める。**
本番が始まってからでは初日の情報収集に間に合わない。

投稿数の傾向として、**トレモ期間の方が検証動画は多い**。本番期間は各自が実際に凸を消化する時間帯で、
新規の検証動画は相対的に減る。
