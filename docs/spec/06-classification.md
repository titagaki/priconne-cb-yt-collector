# 06. 判定ロジック

実装先: `src/priconne_cb_collector/domain/classify/`（`normalize.py` / `boss.py` / `battle_type.py` / `damage.py`）

判断の理由は [discussion/判定ロジック](../discussion/classification.md)、
対象となる表記の実態は [game/動画の表記慣習](../game/video-conventions.md) を参照。

判定はすべて **タイトル + 説明文（先頭500文字）** を対象に、正規化を行ってから実施する。

## 1. 正規化

1. 全角英数記号 → 半角（NFKC 正規化）
2. アルファベット → 小文字化
3. カタカナはそのまま（ひらがな化はしない）
4. 空白・記号（`【】[]()「」/|-・`）を区切りとして扱う

## 2. ボス判定

### 2.1 優先度A: ボス名マッチ

- `bosses.yaml` の `name` および `aliases` を正規化した文字列で部分一致検索。
  **`aliases` は `name` を置き換えるのではなく補う**（`aliases` を書いても `name` は常に候補に残る）
- 1 体だけにヒットした場合、その `index` を `boss_index` に記録し、`match_source = "boss_name"` を立てる
- **2 体以上にヒットした場合は判定不能**として扱う（`boss_index = NULL`, `match_source = NULL`）。
  投稿先は親チャンネルになる（[08](08-discord-posting.md)）
- **ヒットしたボスとマッチした文字列はログに残す**（複数ヒットした場合も含め、DB には保存しない）。[10](10-non-functional.md) §2

### 2.2 優先度B: EX表記

EX表記を**検索クエリには使わない**。すでに他の経路で収集済みの動画に対する分類手段としてのみ使う。

適用条件（すべて満たす場合のみ）:

1. 優先度A（ボス名）が 1 体もヒットしなかった。
   **複数ヒットして判定不能になった場合は EX表記へフォールバックしない**（ボス名の方が確度が高いため）
2. `config.classify.enable_ex_notation == true`
3. 本文中にプリコネ文脈語が含まれる（`プリコネ` / `クラバト` / `クランバトル` / `priconne`）
4. 動画の `publishedAt` が**収集期間内（収集開始以降）**

マッチパターン（`N` は 1〜5）:

```
ex\s?N        →  ex1, EX 1, ex-1
Nボス         →  1ボス, 4ボス
ボスN         →  ボス3
第N[ボス弾]   →  第2ボス
[①-⑤]        →  丸数字
```

マッチしたら `boss.index == N` のボスに割り当て、`match_source = "ex_notation"` を記録する。

**衝突時のルール:** ボス名と EX番号の両方がヒットし、かつ食い違う場合は**ボス名を優先**し、WARN ログを出す。

## 3. 通常 / 持ち越し 判定

出力は 3 値: `normal` / `carryover` / `unknown`

### 3.1 持ち越し判定パターン（優先）

```
持ち越し / 持越し / 持越 / もちこし
(\d{1,2})\s?(秒|s)\s?(持ち越し|持越し|持越|から|スタート|start)
(持ち越し|持越し|持越)\s?(\d{1,2})\s?(秒|s)
(\d{1,2})\s?s          ← 持ち越し語を伴わない素の秒数。1〜89 のみ
```

- 数値がキャプチャできた場合は `carryover_sec` に格納（1〜90 の範囲外は無効として捨てる）
- 秒の単位は `秒` と `s` の両方を受ける。**実データでは `s` が主流**
- 素の `Ns` を持ち越しの根拠にするのは、フルタイムが90秒であるため。**90 は除外**し、`90秒` / `90s` 単独は通常（フルタイム）として扱う
- **`持ち` 単体はパターンに含めない**
- **`繰り越し` / `繰越` はパターンに含めない**（このゲームでは使われない表記）

### 3.2 通常判定パターン

```
通常 / 通常編成 / 通常凸
初手 / 初凸 / 素凸 / 1凸目
フルタイム / 90秒 / 90s / フル(?!オ)
```

否定先読みは `(?!オート)` ではなく **`(?!オ)`** とする。

### 3.3 判定順序

1. 持ち越しパターンにヒット → `carryover`
2. 通常パターンにヒット → `normal`
3. どちらもなし → `unknown`

両方ヒットした場合は持ち越しを優先する。`フルオート` は `フル`（フルタイム＝通常）に**含めない**
（§3.2 の否定先読み）。フルオートかどうか自体は判定しない。

## 4. ダメージの抽出（任意項目、取れなくてよい）

| 項目 | パターン例 | 格納 |
|---|---|---|
| ダメージ | `(\d+(?:\.\d+)?)\s?億(\d+万)?`, `(\d+(?:\.\d+)?)\s?万` | `damage: int`（万単位に正規化） |

**タイトル/説明文から抽出するのはダメージだけ。**ボスの「段階」、フルオート / 手動、
トレモかどうかは**抽出しない**。

正規化ルール:

- `億` は 10,000 倍して万単位にする（`1.5億` → `15000`）
- `2億3000万` のように億と万が併記された場合は合算する（→ `23000`）
- 桁区切りのカンマは除去してから解釈する（`2,150万` → `2150`）

抽出失敗は `null` とし、判定全体を失敗させないこと。

トレモ動画は**除外も区別もしない**。本番動画と同じように扱って投稿する。

## 5. 除外フィルタ

以下に該当する動画は**保存はするが投稿しない**（`status = "filtered"` として理由付きで記録）:

| 条件 | `filter_reason` |
|---|---|
| `duration` が `min_duration_seconds` 未満 | `too_short` |
| `duration` が `max_duration_seconds` 超過 | `too_long` |
| 配信中・配信予定（`exclude_live: true` の場合） | `live` |
| タイトルに `title_ng_words` を含む | `ng_word` |
| ボス判定が `unknown` かつ `on_boss_unknown == "skip"` | `boss_unknown` |

`on_boss_unknown` の既定は `post_as_unknown`。**既定ではボス判定できなくても投稿する**（[01](01-overview.md) §2）。
