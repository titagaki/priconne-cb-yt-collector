# 01. 概要・スコープ・用語

## 1. 目的

プリンセスコネクト!Re:Dive のクランバトル（以下クラバト）期間中、YouTube に投稿されるボス攻略動画を自動収集し、Discord チャンネルへ投稿する。

ゲーム側の前提（開催日程、ボス、段階、持ち越しなど）は [`docs/game/`](../game/README.md) にまとめる。
本仕様をそう決めた理由は [`docs/discussion/`](../discussion/README.md) にある。

## 2. 基本方針

**やることは「動画のリストをとってきて投稿する」だけ。**これに含まれないものは作らない
（[削減の記録](../discussion/reductions.md)）。

- ボス構成は運用者が `bosses.yaml` に手動設定する（自動取得はしない）
- Bot の状態は「収集する / しない」の2値のみ（[03](03-schedule.md)）
- 収集期間外はポーリングを停止し、YouTube へ通信しない
- **投稿先を決めるためだけにボス名を見る。**それ以外の判定はしない（[04](04-collection.md)）
- **取りこぼすくらいなら、関係ない動画が混ざってよい。**判定に迷う場合は投稿する側へ倒す

## 3. スコープ

### 3.1 やること

1. ボス名の OR クエリで YouTube を検索する（[04](04-collection.md)）
2. まだ投稿していない動画を選ぶ（[02](02-architecture.md) §3）
3. タイトルからボスを特定し、そのボスのチャンネルへ投稿する（[04](04-collection.md)）

`/start` `/stop` `/status` で収集の開始・停止・確認ができる（[03](03-schedule.md)）。

### 3.2 やらないこと

- 動画のダウンロード・再エンコード
- 動画内容の解析（サムネイル画像認識、字幕解析など）
- ニコニコ動画・Twitter/X など YouTube 以外のソース
- 編成内容（キャラ構成）の抽出
- ボスの「段階」の抽出・管理
- **通常 / 持ち越しの判定、ダメージ・フルオート・トレモの抽出**
- **Discord チャンネルやスレッドの作成**（投稿先は運用者が用意する）

## 4. 用語

本仕様で使う語のうち、ゲーム用語は [`docs/game/`](../game/README.md) を参照。
以下は Bot 側の語。

| 用語 | 意味 |
|---|---|
| 収集期間 | Bot が YouTube を巡回している間。`/start` に始まり `/stop` に終わる（[03](03-schedule.md)） |
| `cb_period` | 収集期間の識別子。`"YYYY-MM"` 形式 |
| 判定不能 | タイトルからボスを1体に絞れなかった動画。ヒット0件と複数ヒットの両方を指す。fallback チャンネルへ投稿する（[04](04-collection.md)） |
