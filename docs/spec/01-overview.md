# 01. 概要・スコープ・用語

## 1. 目的

プリンセスコネクト!Re:Dive のクランバトル（以下クラバト）期間中、YouTube に投稿されるボス攻略動画を自動収集し、Discord チャンネルへ投稿する。

## 2. 基本方針

- 毎月ボスが入れ替わるため、**ボス構成は運用者が手動設定する**（自動取得はしない）
- **稼働はトレーニングモード開始時点（クラバト開始の3日前）から。** この時点でボスが判明し、検証動画が出始めるため
- 稼働期間外はポーリングを停止する
- 収集した動画は「どのボスか」「通常編成か持ち越しか」を判定してラベル付けする
- 誤爆（無関係な動画の投稿）より取りこぼしを許容する。ノイズが多いと通知として機能しなくなるため

## 3. スコープ

### 3.1 やること

- YouTube からの動画収集（RSS + Data API v3） → [05](05-collection.md)
- ボス判定・通常/持ち越し判定 → [06](06-classification.md)
- 重複排除 → [07](07-persistence.md)
- Discord への Embed 投稿 → [08](08-discord-posting.md)
- スラッシュコマンドによる設定変更・状態確認 → [09](09-slash-commands.md)

### 3.2 やらないこと

- 動画のダウンロード・再エンコード
- 動画内容の解析（サムネイル画像認識、字幕解析など）
- ニコニコ動画・Twitter/X など YouTube 以外のソース
- 編成内容（キャラ構成）の抽出

## 4. 用語

| 用語 | 意味 |
|---|---|
| クラバト | クランバトル。月末数日間に開催されるレイドイベント |
| ボス | クラバトに登場する敵。1周につき 5 体を順に討伐する |
| 段階 | 周回が進むごとにボスが強化されるフェーズ（1〜5段階目） |
| 通常 | 満タンの残タイム（90秒）で挑む編成 |
| 持ち越し | 前の凸で討伐した際に得た残り時間（最大90秒）で挑む編成 |
| EX表記 | ボスを名前ではなく番号で表す記法（ex1〜ex5、1ボス 等） |

> **用語の衝突に注意:** 「段階」（ボスの強化フェーズ 1〜5）と、Bot の稼働「フェーズ」（idle / training / battle）は別物。
> DB 上も `boss_phase` と `discovered_phase` で名前を分けている（[07](07-persistence.md)）。
