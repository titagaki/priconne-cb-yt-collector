# 01. 概要・スコープ・用語

## 1. 目的

プリンセスコネクト!Re:Dive のクランバトル（以下クラバト）期間中、YouTube に投稿されるボス攻略動画を自動収集し、Discord チャンネルへ投稿する。

ゲーム側の前提（開催日程、ボス、段階、持ち越しなど）は [`docs/game/`](../game/README.md) にまとめる。
本仕様をそう決めた理由は [`docs/discussion/`](../discussion/README.md) にある。

## 2. 基本方針

- ボス構成は運用者が `bosses.yaml` に手動設定する（自動取得はしない）
- 収集はトレーニングモード開始時点から開始する
- Bot の状態は「収集する / しない」の2値のみ（[04](04-schedule.md)）
- 収集期間外はポーリングを停止し、YouTube へ通信しない
- 収集した動画は「どのボスか」「通常編成か持ち越しか」を判定してラベル付けする
- **取りこぼすくらいなら、関係ない動画が混ざってよい。**判定に迷う場合は投稿する側へ倒す

## 3. スコープ

### 3.1 やること

- YouTube からの動画収集（Data API v3 検索） → [05](05-collection.md)
- ボス判定・通常/持ち越し判定 → [06](06-classification.md)
- 重複排除 → [07](07-persistence.md)
- Discord への Embed 投稿 → [08](08-discord-posting.md)
- スラッシュコマンドによる設定変更・状態確認 → [09](09-slash-commands.md)

### 3.2 やらないこと

- 動画のダウンロード・再エンコード
- 動画内容の解析（サムネイル画像認識、字幕解析など）
- ニコニコ動画・Twitter/X など YouTube 以外のソース
- 編成内容（キャラ構成）の抽出
- ボスの「段階」の抽出・管理

## 4. 用語

本仕様で使う語のうち、ゲーム用語は [`docs/game/`](../game/README.md) を参照。
以下は Bot 側の語。

| 用語 | 意味 |
|---|---|
| 収集期間 | Bot が YouTube を巡回している間。`/start` に始まり `/stop` に終わる（[04](04-schedule.md)） |
| `cb_period` | 収集期間の識別子。`"YYYY-MM"` 形式 |
| EX表記 | ボスを名前ではなく番号で表す記法。判定の入力として扱う（[06](06-classification.md)） |
| 判定不能 | ボスを1体に絞れなかった動画。ヒット0件と複数ヒットの両方を指す（[06](06-classification.md)） |
